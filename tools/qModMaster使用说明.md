# qModMaster 调试工具

## 位置与用途

第三方工具发布包位于 `tools/qModMaster-Win64-exe-0.5.3-beta/`，启动文件为其中的 `qModMaster/qModMaster.exe`。它作为电脑端 Modbus 主站，通过 USB 转 RS485 与本工程采集温控板通信，可读寄存器及检查收发帧。

此目录保存可执行程序和运行依赖，不是本项目自研上位机的源码。保留同目录 DLL、插件、帮助文件和原始第三方版权说明，使用时直接启动 EXE，无需从 DLL 中逐个安装。目录名标注版本为 0.5.3-beta，实际程序版本以软件界面为准。

## 本工程连接参数

| 项目 | 设置 |
| --- | --- |
| 通信模式 | Modbus RTU |
| 串口 | USB 转 RS485 对应的 COM 端口，按设备管理器选择 |
| 波特率 | 9600 |
| 数据位、校验、停止位 | 8 位、无校验、1 位，即 8N1 |
| 从机地址 | 1 |
| 响应超时 | 至少 500 ms，可先设为 1 秒 |
| 读取功能 | 0x03，读取保持寄存器 |
| 写入功能 | 0x06，写单个保持寄存器 |

RS485 通道需按硬件说明配置 H3 跳线；USART2 的 115200 8N1 是独立调试输出，不能用作本项目的 Modbus 串口配置。具体接线和寄存器表见 [固件说明](../code/code/README.md)。

## 首次读取

先使用 0x03 读取系统状态和四路温度，对应协议地址 `0x0000`～`0x0004`，共 5 个寄存器。qModMaster 的 Base Address 设置会影响界面输入：以 0 为基址时起始地址填 0，以 1 为基址时填 1；使用总线监视确认请求帧中的实际起始地址是 `0x0000`。

温度按有符号 16 位解释，再除以 100 得到摄氏温度；`0x8000` 表示无效，不能当成正常温度。写入目标温度或加热使能会改变设备状态，操作前核对目标寄存器与固件说明。

## 文件管理

发布包内第三方原始文档和许可说明保持原样，中文操作说明写在本文件。工具生成的日志和本机 INI 配置按 `.gitignore` 留在本机，避免把串口号、窗口状态及历史调试日志提交到仓库。
